📚 1. Формулаларды үйрен

Қысқаша көбейту формулалары өрнектерді тез ықшамдауға көмектеседі.

Қосындының квадраты(a + b)² = a² + 2ab + b²
Айырманың квадраты(a − b)² = a² − 2ab + b²
Квадраттар айырмасыa² − b² = (a − b)(a + b)
Қосындының кубы(a + b)³ = a³ + 3a²b + 3ab² + b³
Айырманың кубы(a − b)³ = a³ − 3a²b + 3ab² − b³
Кубтар қосындысыa³ + b³ = (a + b)(a² − ab + b²)
Кубтар айырмасыa³ − b³ = (a − b)(a² + ab + b²)

🧠 Есте сақтауға арналған лайфхак

Квадратта: бірінші квадрат +/− екі еселенген көбейтінді + екінші квадрат.

Квадраттар айырмасында: «айырма × қосынды» деп есте сақта.

✏️ 2. Мысалдар

Мысал 1: (x + 3)²

(a + b)² = a² + 2ab + b²
a = x, b = 3
Жауабы: x² + 6x + 9
Мысал 2: (x − 5)²

(a − b)² = a² − 2ab + b²
Жауабы: x² − 10x + 25
Мысал 3: x² − 25

x² − 5² = (x − 5)(x + 5)
Жауабы: (x − 5)(x + 5)
